What it does

classly / registration

Course Registration

A three-step form: student details, courses, then fees and payment. It takes individual courses and package deals, works out the total as you pick, and keeps track of what's paid and what's still due. It also records which account registered the student, so the referral credit goes to the right person.

classly / class counter

Class Counter

Tick off classes as they happen. Today's classes sit in one place, and you can see your own recent ticks.

classly / courses

Courses & Pricing

The list of courses and what each one costs, in one place you can edit.

classly / staff

Staff Accounts

Manage who can sign in.

classly / analytics

Analytics

An overview of how the center is doing.

Try it

It's a working app, so you can use it yourself.

  1. Open the demo.

  2. On the sign-in screen, pick any account under "Try it as". No signup.

  3. Register a student, tick a class, look at the analytics.

Open the live demo

Everything you do is saved only in your browser. The Reset demo data button puts it back the way it was.

How it's built

The demo is plain HTML and JavaScript. It runs in your browser and saves to the browser's localStorage, so there is no server and no account. It is a demo, not production sign-in.

How it went

Classly was built as a demo for an English language teaching agency. It didn't lead to a sale. The app still works from start to finish, so it lives here as a project you can try.
