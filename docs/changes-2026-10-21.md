# Changes, 21 October 2026

## Fixed
- **Home page on phones.** The logo badge sat between two blocks of text. It is now a small crest above the headline, so the order is badge, headline, buttons, then the next section. The analytics notice is also a slimmer bar on phones, so it no longer covers the headline.
- **Google "not receiving data".** The tag was only added after a visitor pressed Allow, so Google's own check never saw it. It is now on every page using Google Consent Mode, with storage off until the visitor allows it (see `docs/analytics.md`, including the privacy trade-off and the one-line switch back). The privacy page and the tests match. After you deploy: open the site, press Allow, check the Realtime report. Not verified from here.
