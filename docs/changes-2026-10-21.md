## Added 22 October, later: lessons without a deploy
- You wanted new lessons to appear without a Netlify deploy (production deploys cost 15 of the free plan's 300 monthly credits). The first version of the database work did not do that: lessons were stored in Turso but still built into static pages, so each one still meant a push. This fixes it.
- `netlify/functions/learn.mjs` serves `/learn/`, each lesson and `/sitemap.xml` from published lessons in the database, cached for 5 minutes at the edge. Publish in the admin panel and it is live; nothing to push.
- `netlify.toml` routes those addresses to it, and skips a production deploy when a push changes only docs, tests, tools, the schema, the static lesson copies or the sitemap.
- The live pages are byte-identical to the Python renderer's (tested with the same lessons both ways). 30 new checks, plus a test of the skip-deploy rule.
- Needs, once: a read-only Turso token and two Netlify environment variables (docs/database.md). Not yet tried on real Netlify or real Turso: do it on a free deploy preview first.
